# Task Summary

## Goal and outcome
- Goal: Deliver runtime prompt artifacts that improve hierarchical orchestration quality at decomposition and re-review boundaries, while preserving strict prompt IO contract compatibility.
- Outcome: Added and integrated templates for epoch decomposition, plan decomposition, and re-review/unblock decisions; updated prompt artifact indexing; and resolved the auto-merge conflict in `.ai-task-summary.md`.

## Key code changes
- Added `prompts/epoch-to-phases.md`:
  - Defines epoch-tier responsibilities (strategic scope, milestone slicing, cross-tier dependency reasoning, risk front-loading).
  - Requires epoch inputs (`epoch_metadata`, `epoch_spec`, project constraints, DAG state, repo context, unresolved blockers).
  - Defines bounded decomposition passes with explicit stop/escalate behavior.
  - Includes full structured output shape with required contract fields plus `phase_children`, `cross_tier_dependency_reasons`, and `decomposition_fingerprint`.

- Added `prompts/plan-to-subplans-and-tasks.md`:
  - Defines deterministic `item_type` selection (`sub_plan` vs `execution_task`) with default-to-`execution_task` behavior.
  - Enforces parser-compatible YAML and approval/topology constraints.
  - Adds recursion-depth guard and structured `plan_decomposition` extension with per-item `decomposition_fingerprint`.

- Added `prompts/re-review-unblock.md`:
  - Defines single-action `re_review(node)` outputs: `unblocked`, `still_blocked`, `spawn_delta_work`.
  - Includes anti-thrash/debounce behavior and bounded retry/escalation requirements.
  - Adds structured `re_review` payload extension for blocker evidence, gap hashes, retry guidance, and escalation.

- Updated prompt index:
  - `prompts/README.md`
  - Includes runtime artifact entries for `epoch-to-phases.md`, `plan-to-subplans-and-tasks.md`, and `re-review-unblock.md`.
