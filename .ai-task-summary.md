# Task Summary

## Goal and outcome
Goal: Implement the SQLite ownership split per `docs/adr-sqlite-persistence-split.md`.
Outcome: Completed. App/global entities remain in `data/app.sqlite`, and project-local entities now live in per-project databases at `<project.base_path>/.ai-coding/project.sqlite`.

## Key code changes
- Split migrations in `server/src/db/migrations.ts` into app DB and project DB schemas.
- Refactored DB layer in `server/src/db/index.ts`:
  - Added `appDb` for global tables.
  - Added project DB open/init/cache/validation.
  - Added project metadata/config handling (`project_metadata`, `project_config`).
  - Added explicit invariants in code comments:
    - single source of truth per table,
    - no cross-file foreign keys,
    - cross-DB linkage by IDs only.
- Added `server/src/db/ownership.ts` for project/task DB context resolution.
- Rewired persistence access across routes/services/websocket gateways to enforce DB ownership boundaries.
- Updated model typing in `server/src/types.ts` and persistence docs in `README.md`.
