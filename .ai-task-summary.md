# Task Summary

## Goal and Outcome
- Goal: Add a coordinator prompt template for `synthesize(parent)` that aggregates child outputs into parent requirement-to-evidence coverage, including uncovered requirement detection and deduplicatable gap identifiers.
- Outcome: Implemented a new prompt artifact `prompts/synthesis.md` with a strict machine-readable synthesis schema (coverage matrix, uncovered requirements, candidate gap hashes) and updated prompt index documentation to include it.

## Key Code Changes
- Added `prompts/synthesis.md`.
  - Defines synthesis purpose and required inputs:
    - `parent.spec`
    - `parent.requirements`
    - `children.outputs`
    - `repo.diffs`
    - `dependency.outcomes`
  - Supports parent tiers: `epoch | phase | plan | task`.
  - Requires dual output shape:
    - Natural-language rationale
    - Structured payload (aligned with prompt contract baseline fields).
  - Adds `synthesis` payload section with:
    - `summary` (`confidence`, `status`, `narrative`)
    - `coverage_matrix` (explicit per-requirement row model)
    - `uncovered_requirements`
    - `candidate_gap_hashes` (`sha256` + deterministic hash basis).
  - Adds explicit coverage rules to keep the matrix machine-valid and auditable.
- Updated `prompts/README.md` to include:
  - `synthesis.md` - parent synthesis template for requirement-to-evidence coverage aggregation.
