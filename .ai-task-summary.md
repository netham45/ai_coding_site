# Task Summary

## Goal and outcome
- Goal: Add a coordinator prompt template for `re_review(node)` that determines whether a node is truly unblocked, still blocked, or requires new delta child work.
- Outcome: Created a new runtime prompt artifact that enforces single-action re-review decisions, dependency/child completion triggers, anti-thrash/debounce behavior, and bounded retry/escalation semantics aligned to the existing prompt contract.

## Key code changes
- Added new prompt template:
  - `prompts/re-review-unblock.md`
  - Defines required re-review inputs beyond shared inputs:
    - changed deps/children/events
    - latest synthesis/verification state
    - iteration counters
    - prior gap hashes
  - Defines re-review decision logic:
    - `unblocked` only when required deps and required children completion triggers are satisfied
    - `still_blocked` when blockers remain without new actionable gap
    - `spawn_delta_work` when a newly actionable gap exists
  - Enforces exactly one action output.
  - Adds anti-thrash/debounce rules:
    - avoid repeated action when blocker hash unchanged
    - avoid duplicate delta work for known unresolved `gap_hash`
    - require materially new signal before spawning delta work
    - stop auto-looping and escalate when budget is exhausted
  - Adds structured payload extension for re-review with:
    - `re_review.action`
    - blocker/trigger evidence
    - `gap_hash_candidates`
    - bounded `retry_guidance`
    - `escalation` flag/reason
  - Adds explicit output constraints, including escalation requirements when retry/replan budget is exhausted.

- Updated prompt artifact index:
  - `prompts/README.md`
  - Added `re-review-unblock.md` to the documented runtime template list.
