# Task Summary

## Goal and outcome
- Goal: Show task completion summary on the Task Info page when available.
- Outcome: Implemented conditional rendering of a new "Completion Summary" section in the Task Info tab that displays only when `task.result` contains non-whitespace content.

## Key code changes
- Updated `web/src/pages/TaskDetailPage.tsx`.
- Added a computed value:
  - `const completionSummary = task.result.trim();`
- Added a conditional UI block in Task Info:
  - Renders a `Completion Summary` heading and content block only when `completionSummary` is truthy.
  - Displays the summary using an existing `Code` container with `whiteSpace="pre-wrap"`.

## Tests/validation performed
- Ran web build:
  - `npm run build -w web`
- Result: Build succeeded.
- Notes: Existing Vite chunk-size warning appeared (non-blocking, unrelated to this change).

## Remaining risks or follow-ups
- UI behavior depends on backend continuing to populate `task.result`; if runtime summary capture fails upstream, section will not appear (by design).
- Optional follow-up: Add an explicit empty-state message if product UX wants users to know summary capture has not occurred yet.
