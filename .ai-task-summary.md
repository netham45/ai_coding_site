## Goal and outcome
- Goal: Merge two active workstreams:
  - CLI-facing help/prompt/docs updates for the `acs` invocation model with nested-directory root discovery guidance.
  - Project SQLite relocation from repo-local `.ai-coding/project.sqlite` into shared data storage at `data/projects/<projectId>/project.sqlite`.
- Outcome: The codebase now documents and enforces `acs`-first CLI usage with explicit root-not-found remediation, while project DB persistence uses centralized per-project paths with legacy-path migration compatibility.
