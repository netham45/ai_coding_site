## Goal and outcome
- Goal: Add one backend create endpoint the UI can use for all top-level user tiers (`epoch`, `phase`, `plan`, `task`) while preserving existing persistence and dependency validation behavior.
- Outcome: Implemented a unified node creation route that supports all four tiers, maps them to existing task storage conventions, and returns serialized node data compatible with current APIs.

## Key code changes
- Added `POST /api/projects/:projectId/nodes` in `server/src/routes/tasks.ts`.
- Added request schema support for:
  - `title`, `taskPrompt`, `nodeTier`, `aiCommand?`
  - `parentNodeId?`, `dependencyTaskIds?`, `dependencyNodeRefs?`
  - automation flags (`autoMerge`, `autoStart`, `autoMergeOnComplete`, `allowReplanBudgetOverride`).
- Implemented tier-to-mode mapping:
  - `epoch|phase|plan` -> `mode='plan'` and `metadata_json.tier` set to requested tier.
  - `task` -> `mode='execution'` and `metadata_json.tier='task'`.
- Reused existing workspace/branch creation and dependency validation helpers.
- Added integration coverage in `server/src/integration.test.ts` for creating all four tiers through the unified endpoint.
- Added `UserNodeTier` type alias in `server/src/types.ts`.
