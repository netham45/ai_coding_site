# Task Summary

## Goal and outcome
- Goal: implement a split SQLite architecture with global data in `data/app.sqlite` and per-project data in `<project.base_path>/.ai-coding/project.sqlite`, plus robust DB helpers.
- Outcome: completed. Added app/project DB managers, shared PRAGMA setup, project DB metadata bootstrap/validation, and safe project DB handle caching/reuse. Existing app DB consumers remain compatible.

## Key code changes
- Added `server/src/db/sqlite.ts`:
  - `openSqliteDatabase(dbPath)` and shared PRAGMAs:
  - `foreign_keys = ON`, `journal_mode = WAL`, `busy_timeout = 5000`.
- Added `server/src/db/appDb.ts`:
  - Global DB path management for `data/app.sqlite`.
  - Moved app DB initialization, baseline migration, legacy column/index guards.
  - Preserved `ensureLocalUser()` behavior.
- Added `server/src/db/projectDb.ts`:
  - Project DB location: `<project.base_path>/.ai-coding/project.sqlite`.
  - Metadata table management (`project_metadata`) with:
  - `project_id`, `schema_version`, `created_at`, `updated_at`.
  - Validation enforces:
  - exactly one metadata row,
  - expected `project_id`,
  - expected schema version,
  - valid timestamp format and ordering.
  - Added cached/reused handle lifecycle helpers:
  - `ensureProjectDb`, `getProjectDb`, `closeProjectDb`, `closeAllProjectDbs`.
- Updated `server/src/db/index.ts`:
  - Re-exported app and project DB helpers from one entrypoint.
  - Kept compatibility export for `db` and `ensureLocalUser`.
- Updated `server/src/routes/projects.ts`:
  - On successful clone, now initializes/validates project DB via `ensureProjectDb({ projectId, basePath })` before marking the project ready.

## Tests/validation performed
- Ran `npm run build -w server`.
- Result: successful TypeScript compile with no errors.

## Remaining risks or follow-ups
- Project DB currently validates/boots metadata only; project-scoped operational tables are not migrated yet.
- Handle cleanup helpers exist, but no explicit process-shutdown wiring was added yet.
- No dedicated tests yet for metadata mismatch/error paths (wrong `project_id`, schema drift, invalid timestamps).
