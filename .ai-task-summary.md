## Goal and outcome
- Goal: Make CLI commands robust when run from `/server` or deeper subdirectories by discovering the ai-coding-site workspace root from `process.cwd()` using durable markers, and fail clearly when outside a workspace.
- Outcome: Implemented reusable root discovery, integrated it into CLI startup and shared path resolution, and verified behavior via integration tests/build/help command.

## Key code changes
- Added reusable root discovery utility:
  - `server/src/utils/workspaceRoot.ts`
  - Walks parent directories from `process.cwd()`.
  - Detects valid root via:
    - top-level `package.json` with `name: "ai-coding-site"`
    - workspaces including `server` and `web`
    - existing top-level directories `server`, `repos`, `web`
  - Exposes:
    - `discoverWorkspaceRoot(startDir?)`
    - `getWorkspaceRootOrThrow(startDir?)` with clear guidance error.

- Updated shared path resolution:
  - `server/src/utils/paths.ts`
  - Replaced module-location-based root with `getWorkspaceRootOrThrow()`.
  - `dataRoot` and `reposRoot` now resolve from discovered workspace root (unless env overrides are set).

- Updated CLI startup behavior:
  - `server/src/cli/index.ts`
  - Added early `getWorkspaceRootOrThrow(process.cwd())` in `run()`.
  - Ensures non-zero exit with clear error when CLI is invoked outside an ai-coding-site workspace.

- Added CLI integration test coverage for nested cwd execution:
  - `server/src/integration.test.ts`
  - Added `runCliFromCwd(...)` helper.
  - Added test: `cli commands work from nested server directories`.

## Tests/validation performed
- Ran CLI help from `/server`:
  - `npm run cli -- --help`
  - Result: success, full command list displayed.

- Ran integration test suite filtered to CLI subcommands:
  - `npm run -s test -- --test-name-pattern "CLI subcommands"`
  - Result: pass, including new nested-cwd test.

- Ran TypeScript build:
  - `npm run build` (in `server/`)
  - Result: pass.

- Verified failure mode outside workspace:
  - Invoked CLI from a temporary directory.
  - Result: exit code `1` with clear error:
    - `Could not locate the ai-coding-site workspace root ... Run this command from within an ai-coding-site workspace ...`

## Remaining risks or follow-ups
- Detection is intentionally strict (`package.json` name/workspaces + required dirs). If workspace identity changes in future (rename/restructure), update markers in `workspaceRoot.ts`.
- Existing tests cover nested cwd success; if desired, add a dedicated automated integration test for outside-workspace failure path.
