# Task Summary

Goal: Implement the SQLite ownership split from `docs/adr-sqlite-persistence-split.md`.
Outcome: Completed. Global entities are owned by `data/app.sqlite`, and project-local entities are owned by per-project DB files at `<project.base_path>/.ai-coding/project.sqlite`.
